# Comandos de Git para utilizar en el curso

Para ver que cambios llevas realizados puedes escribir

```bash
git status
```

Para agregar todos estos cambios al repo de todos puedes escribir

```bash
git add .
```

Para **registrar** todos estos cambios en el repo global puedes escribir

```bash
git commit -m "DESCRIPCIÓN DE TUS CAMBIOS"
```

Para enviar todos estos cambios al repo global puedes escribir

```bash
git push
```

Recuerda que al escribir **git push** es probable que tu terminal te pida tu nombre de usuario y contraseña, para la contraseña debes usar un **Personal Access Token (PAT)**.
